## 放置方式

事業方案採完整寬幅圖，延續深藍底、細青藍框與圓角。先閱讀建場服務，再看工具配置，最後接回經營模式與建場討論。手機保留全部五款工具，點擊圖片或下方文字可另開完整大圖；鍵盤 Focus 可見。

B2 取代待核准圖形；既有 B2 實洗展示區實際載入原本預留的 `b2-wash-action.webp`，不再因缺少素材而隱藏。M9 更新為業主最新 RAR 的水幕圖。雲端儲值機採原文在左、圖片與原有資料欄在右，手機改上下排列。圖片均維持完整比例與 contain，不裁掉設備或標籤。

## 原始素材與載入

僅使用業主四個 RAR 內的原始 PNG，未重新生成、未替換其他設備。原始 PNG 完整保存於 `lassets/products/source/` 及 `lassets/business/source/`。共 11 張 WebP 衍生檔，quality=80、每張低於 300 KB；主要設備圖與小尺寸共用於中英文。分享圖完整容納產品於 1200×630 深藍畫布，無拉伸或內容裁切。
