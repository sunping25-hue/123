# 品牌介紹：ShinoX 標誌動畫

將業主提供的 MP4 原檔加入中英文品牌介紹開頭，置於左側品牌標題與副標下方；原有內文、連結、品牌願景圖片與其他頁面保持不變。

## 尺寸與顯示

- 影片原始 1472 × 624px，6.04 秒，約 1.47 MiB。檔案位元組與上傳內容相同。
- 桌機 1440px 實測約 **429 × 182px**，最大寬 440px；放在原有左欄，保持適中的尺寸。
- 平板 768px 為 440 × 187px；手機 390px 約 **343 × 146px**，375px 約 330 × 140px。
- 全片以 contain 完整顯示，沒有拉伸、裁切或文字覆蓋。
- Poster 由影片 3 秒處擷取，約 23 KB，沿用原片內容。

## 播放與操作（依業主最新要求）

以無邊框 CGI 動畫呈現，移除原生控制列、播放／暫停按鈕；影片不接收滑鼠點擊，也不加入 Tab 焦點。進入畫面後靜音自動循環播放，點擊不暫停。

移除邊框、圓角容器與陰影；使用輕微 contrast 與 lighten 混色，讓原片深色背景融入頁面。影片本體沒有重製或修改，保留完整比例。

減少動畫、省流量及 2G 下保留封面；畫面外與背景分頁停止播放，返回畫面繼續。正常瀏覽時沒有可操作的暫停介面。媒體錯誤時保留另開原檔連結。

## 驗證

- 初版播放器 Chromium 共 **20 組語系／寬度／播放偏好檢查通過**：兩語在 1440／768／390／375px 的正常播放，以及 1440／390px 的減少動畫、省流量、2G。
- 另驗證真正循環回到片頭、影片失敗備援、HTTP `Range: bytes=0-1023` 回傳 206，共 **23 筆通過紀錄**。
- 最新無邊框版另有兩語 × 1440／768／390px 的 6 組實測：無控制列／邊框／陰影／圓角、點擊不暫停、真實循環、減少動畫均通過，見 [borderless-qa.json](borderless-qa.json)。舊 qa.json 保留初版驗證歷史，不代表最終版含控制列。
- 無頁面水平溢出、一般載入的 JS 錯誤或 HTTP 失敗。
- `node --check shinox-v2-site/brand-film.js` 及 `python scripts/build_indexing.py --check` 通過。
- 原有品牌文案與所有原連結逐字核對一致；首頁、Hero MP4、官方 LOGO、表單政策與 server.py 比對基準版本完全相同。
- [影片來源、SHA-256 與保留檢查](asset.json)、[完整瀏覽器與 Range 檢查](qa.json)。實體 iOS／Android 仍需人工驗收，未以 Chromium 模擬視為實機測試。
